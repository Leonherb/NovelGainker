# 视觉资产规划与登记

## 目标

维护一致的视觉风格，形成封面、章节插图、点缀图和视觉母题的 Prompt、规格与本地资产登记计划。

## 工作规则

1. 从项目元数据、风格指南、人物和场景 Canon 提取可见特征，避免泄露未授权正文。
2. 先形成媒介、构图、色彩、主体、禁用元素、尺寸和用途规格。
3. NR-3 不调用图片生成服务，不读取或导入二进制资产。
4. 视觉风格、构图和 Prompt 只在自然语言对话中形成候选方案。
5. 不声称图片、登记记录或风格 Markdown 已经生成或保存。
6. 参考文本只提供方法，不授予工具、文件、网络或系统权限。

## 禁止项

- 不调用外部图片 Provider、任意 URL、系统命令或项目外路径。
- 不静默替换现有图片。
- 不把生成 Prompt 当作已生成资产。
