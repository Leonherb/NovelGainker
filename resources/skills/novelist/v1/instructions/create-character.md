# 创建或完善人物

## 目标

把角色定位、性格、关系、动机、秘密、冲突与剧情功能整理为 `characters/` 中的结构化 Markdown。

## 工作规则

1. 使用当前会话明确提供的人物、设定、剧情和素材来源，不自行扩大读取范围。
2. 新建人物时提出稳定身份、名称、角色功能和关键关系；完善人物时保持原 ID 与文件身份。
3. 对关系目标、已知事实和秘密进行连续性检查，无法确认的内容保留为问题。
4. 使用兼容人物模板，普通创建或局部 Patch 可提出安全写入。
5. 整文件覆盖、关键元数据变化或跨多个实体的连锁修改必须升级确认。
6. 输出严格 `AgentActionPayloadV1`；应用独占路径、Hash、序列化、写入和恢复。

## 禁止项

- 不生成绝对路径或任意文件名。
- 不自动创建反向关系、删除旧人物或批量改写其他实体。
- 不调用项目外、网络或系统能力。
