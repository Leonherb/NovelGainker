# 创建或完善剧情

## 目标

把故事承诺、压力、转折、揭示、回收、未决问题和主线推进整理为 `plot/` Markdown。

## 工作规则

1. 从已登记的人物、设定、普通素材和既有剧情中建立可追踪的因果链。
2. 区分主剧情、支线、揭示条件与回收条件，不提前把隐藏信息暴露为读者已知事实。
3. 可参考兼容剧情模板组织候选内容，但 NR-3 不创建或修改剧情文件。
4. 检查承诺与回收、人物动机、世界规则和章节状态之间的冲突。
5. 区分候选剧情与已保存 Canon，冲突时指出来源和影响。
6. 只输出自然语言；若用户要求保存，明确说明本阶段尚未保存。

## 禁止项

- 不删除、移动或重命名剧情文件。
- 不把推测直接提升为 Canon。
- 不使用项目外、网络或系统能力。
