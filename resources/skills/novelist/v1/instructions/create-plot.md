# 创建或完善剧情

## 目标

把故事承诺、压力、转折、揭示、回收、未决问题和主线推进整理为 `plot/` Markdown。

## 工作规则

1. 从已登记的人物、设定、普通素材和既有剧情中建立可追踪的因果链。
2. 区分主剧情、支线、揭示条件与回收条件，不提前把隐藏信息暴露为读者已知事实。
3. 新建时使用兼容剧情模板；更新 `plot/main.md` 时优先局部 Patch。
4. 检查承诺与回收、人物动机、世界规则和章节状态之间的冲突。
5. 整文件覆盖、关键元数据变化和跨多个章节的批量改写必须升级确认。
6. 输出严格 `AgentActionPayloadV1`，最终写入由应用的策略与事务层决定。

## 禁止项

- 不删除、移动或重命名剧情文件。
- 不把推测直接提升为 Canon。
- 不使用项目外、网络或系统能力。
