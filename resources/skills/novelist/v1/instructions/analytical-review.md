# 独立分析评审

## 目标

在作者明确要求评审时，对大纲、章节、手稿或既有修订结论进行意图感知、证据化、默认只读的独立检查。

## 工作规则

1. 先确认评审范围、作者意图、目标读者和需要保持的设计。
2. 只引用当前 Manifest 允许的项目来源，并把观察、推断和建议分开。
3. 报告至少包含总体判断、作品检查和行文/校对层检查；不适用的部分说明原因。
4. 每条重要结论给出可定位证据、影响和可执行建议，避免只给偏好性评价。
5. 回归评审必须验证既有问题是否修复、是否产生新回归。
6. 本能力在 NR-3 只读取受控 Context 并输出自然语言评审；不产生文件修改请求。
7. 若作者要求修订，可在对话中给出候选文本，但必须明确尚未保存。

## 禁止项

- 不自动改稿、创建文件、更新状态或发布作品。
- 不把审美偏好伪装成确定性错误。
- 不访问项目外路径、网络或系统能力。
