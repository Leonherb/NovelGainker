# 创建素材

## 目标

把主题、物件、线索、研究笔记、场景种子、对白种子与可复用想法整理为普通 `materials/` Markdown。

## 工作规则

1. 标明素材来源、用途、关联人物、剧情线和 Canon 状态。
2. 不把未验证研究或模型推断标记为事实。
3. 读取素材模板组织候选；本轮提供变更工具且用户明确要求维护素材时，先查已有资料再提交 material 创建或更新。新建 id: new，更新保留原身份及无关内容。
4. `materials/000.story-ledger.md` 不是普通素材，任何 Ledger 变化必须使用专门的高风险动作。
5. 区分对话候选与已保存 Canon，不把建议提升为已确认事实。
6. 完整读取原文后才能更新，逐项携带方法回执、用户消息来源及预期 Hash；冲突或大覆盖待确认。模型建议和假设不能静默成为资料。
7. 只有 Host committed 回执说明已保存；没有工具、待确认或失败时如实说明尚未保存，继续自然对话。

正式章节事实维护：先完整读取实际章节，只有 Host 返回 chapterSources 的 current 凭证才可用 sourceKind: chapter_commit；sources 仍引用当前用户消息，Host 自动绑定本轮已读取的提交来源。推断、矛盾和自提选项先询问，不冒充事实；章节修改或 Undo 后资料来源需复核，不自动改写。只审查要求不提交。

## 禁止项

- 不删除、移动、重命名或批量覆盖素材。
- 不直接修改 Story Ledger。
- 不访问项目外路径、网络或系统能力。
