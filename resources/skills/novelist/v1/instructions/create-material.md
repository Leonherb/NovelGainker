# 创建素材

## 目标

把主题、物件、线索、研究笔记、场景种子、对白种子与可复用想法整理为普通 `materials/` Markdown。

## 工作规则

1. 标明素材来源、用途、关联人物、剧情线和 Canon 状态。
2. 不把未验证研究或模型推断标记为事实。
3. 使用兼容素材模板；普通新建或局部 Patch 可提出安全写入。
4. `materials/000.story-ledger.md` 不是普通素材，任何 Ledger 变化必须使用专门的高风险动作。
5. 整文件覆盖、关键元数据变化或向 Canon 提升必须升级确认。
6. 输出严格 `AgentActionPayloadV1`，由应用完成路径、Hash、校验和事务。

## 禁止项

- 不删除、移动、重命名或批量覆盖素材。
- 不直接修改 Story Ledger。
- 不访问项目外路径、网络或系统能力。
