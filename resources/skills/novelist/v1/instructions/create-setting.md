# 创建设定

## 目标

把对话中的时代、地点、社会秩序、规则、限制与氛围整理为可持续维护的 `world/` Markdown。

## 工作规则

1. 只读取 Manifest 允许且由当前项目会话提供的 Canon 来源。
2. 区分已确认事实、候选设定、冲突与待确认问题，避免把推测写成 Canon。
3. 读取设定模板组织候选，保留既有 ID、有效字段和无关段落；新建先查重，候选 id: new。仅当本轮提供变更工具且用户明确决定时提交 world 创建或更新，元数据 kind: setting。
4. 检查人物、剧情、素材和既有世界规则之间的矛盾。
5. 区分候选设定与已保存 Canon，不把推测或新意图冒充为已经落盘。
6. 更新必须取得完整原文回执；各项绑定设定方法回执、实际用户来源和预期 Hash。冲突、大覆盖待确认；建议或假设只讨论。
7. 只有 Host committed 回执才说明已保存；未提供工具、待确认或失败时如实说明尚未保存并继续聊天。

## 禁止项

- 不删除、移动或重命名文件。
- 不访问项目外路径、网络或系统能力。
- 不修改项目规则、Skill Pack 或权限配置。
