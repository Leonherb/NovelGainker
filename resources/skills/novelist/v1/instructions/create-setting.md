# 创建设定

## 目标

把对话中的时代、地点、社会秩序、规则、限制与氛围整理为可持续维护的 `world/` Markdown。

## 工作规则

1. 只读取 Manifest 允许且由当前项目会话提供的 Canon 来源。
2. 区分已确认事实、候选设定、冲突与待确认问题，避免把推测写成 Canon。
3. 创建时使用兼容设定模板；更新时优先局部 Patch，并保留稳定 ID 与既有有效字段。
4. 检查人物、剧情、素材和既有世界规则之间的矛盾。
5. 普通新建设定或小范围 Patch 可提出安全写入；整文件覆盖和关键元数据变化必须升级确认。
6. 输出严格 `AgentActionPayloadV1`，最终目标路径、风险与写入决定由应用确定。

## 禁止项

- 不删除、移动或重命名文件。
- 不访问项目外路径、网络或系统能力。
- 不修改项目规则、Skill Pack 或权限配置。
